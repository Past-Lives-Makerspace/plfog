{% comment %} Busy submit buttons (#713). A form marked data-pl-busy-submit disables every [data-pl-busy] button inside it once it really submits, sets aria-busy="true" (components.css draws the spinner) and swaps the label to "Saving..." (or the form's data-pl-busy-label) until the page leaves. A boosted save is caught on htmx:beforeRequest, a plain one on an uncancelled submit. A failed request or a page restored from the back-forward cache gets its buttons back. A body script, so it re-runs on every boosted arrival: guarded on window and delegated on document (FRONTEND.md, Scripts under hx-boost). The original label is kept in an element property, never an attribute. {% endcomment %}
