{% comment %} Destructive action confirmation modal. Parameters (pass via {% include ... with %}): confirm_id — required, unique DOM id confirm_title — optional, heading (default: "Are you sure?") confirm_message — required, body text confirm_action_url — required (plain-POST mode), form POST target confirm_button_text — optional, button label (default: "Confirm") confirm_button_style — optional, "danger" (default) or "primary" confirm_cancel_text — optional, label for the dismiss button (default: "Cancel") On open the modal records the triggering element and moves focus to the Cancel/dismiss button; every close path (Cancel, Escape, ×, click-outside) restores focus to the opener. confirm_field_name — optional (plain-POST mode), name of one hidden field to carry with confirm_field_value the POST (e.g. run_job=bill_tabs), so the teleported form — which posts OUTSIDE its trigger's form — can still reach a named handler. HTMX mode (optional — when confirm_hx_post is set, the confirm submits via HTMX instead of a full-page POST, so the view can return a toast + swap): confirm_hx_post — HTMX POST target; switches the form to hx-post. confirm_hx_target — CSS selector the response swaps (hx-swap=outerHTML). confirm_hx_vals — optional raw JSON for hx-vals (developer-supplied, e.g. resend). Typed-confirmation mode (optional, plain-POST only — opt-in, backward compatible): confirm_typed_value — when set, a text input appears and the Confirm button stays disabled until the typed text matches this value exactly. confirm_typed_placeholder — input placeholder + label (default: "Type to confirm"). confirm_typed_field_name — POST field name carrying the typed value (default: "confirm"). Note-input mode (optional, opt-in — mirrors the typed-confirmation pattern; works in both plain-POST and HTMX modes): confirm_note_name — when set, an optional single-line text input renders above the buttons and posts under this name (e.g. "reason", "note"). confirm_note_label — the input's label (default: "Note (optional)"). confirm_note_placeholder — the input's placeholder (default: empty). confirm_note_hint — optional hint line under the input. Rich-body mode (optional): confirm_body_include — a template path included after the message, rendered with the including context (per-row conditional copy, links). confirm_warn_message — optional warn-toned line rendered above the buttons. JS mode (optional — when confirm_js is set, Confirm runs that inline JS and closes instead of POSTing a form; used when the confirm must act on the page, e.g. flip a formset row's hidden DELETE field and requestSubmit() its form): confirm_js — inline JS the Confirm button runs. {% endcomment %}
