{% comment %} Reusable overflow ("kebab") actions menu for a table row. Parameters (pass via {% include ... with %}): menu_include — required, template path rendered inside the menu. It inherits the caller's context, so reg / can_manage / viewer_has_refund_authority are available to the menu items. menu_label — required, accessible name for the trigger (e.g. "Actions for Jane Doe"). The menu is position:fixed and placed from the trigger's bounding rect on open, so it escapes the roster table wrapper's overflow:hidden clip; near the viewport bottom it flips upward. Any window scroll or resize dismisses it (a fixed element does not track scroll). See docs/superpowers/plans/2026-08-27-roster-actions-menu.md. {% endcomment %}
