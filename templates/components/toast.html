{% comment %} Toast notifications. Include once per base template (already in hub/base.html and admin/base.html). Dependency-free: plain JS, no Alpine. The script below owns the whole lifecycle, so toasts work regardless of Alpine init order, hx-boost re-inits, or framework state. Triggered by: 1. Server-side (full page / redirect): Django `messages` rendered into a hidden `.hub-messages` list with data-toast-* attributes. Drained on load and after every htmx settle. 2. Server-side (HTMX): HX-Trigger header `showToast` (via hub.toast.trigger_toast). HTMX fires the kebab alias `show-toast`, which the window listener below catches. 3. Client-side: window.showToast('msg', 'success') OR window.dispatchEvent(new CustomEvent('show-toast', {detail: {message, type}})). Types: success (green), error (red), info (blue). Optional position: 'center'. {% endcomment %}
