{% load static %} {% comment %} The five step class composer, shared by templates/classes/teach/class_form.html and templates/classes/admin/class_form.html (design spec §C). Built exactly like the announcement composer (templates/hub/announcement_compose.html): one page, one
, one Alpine x-data holding `phase`, x-show per step, and the .pl-phase-tabs bar. No per-step POST: every field of every step is in the DOM on every render, so one Save posts everything and the server side validation is unchanged. Context (from _composer_context in classes/views.py, plus the form context): form, formset (sessions), faq_formset, offering (may be None on create), mode (anchor_steps_json is rendered autoescaped ON PURPOSE: it sits inside the double quoted x-data attribute, so its quotes must reach the browser as " or they end the attribute.) is_admin — controls instructor / is_private / private_for_name, the discount code URL names, and the step 5 action (Publish instead of Submit for Review) composer_tabs — [{step: ComposerStep, done: bool}], the tab bar with completion marks initial_phase — the step to open on: the first broken step after a failed POST, else ?step= error_steps / error_steps_json / error_summary — the broken steps and their failing field labels anchor_steps_json — DOM id -> step number, for goToField() pipeline, readiness, is_ready — only present once the class has a pk card_group — the genuine CatalogGroup for a saved class (None on create); the card preview frames on steps 2 and 5 render the REAL catalog card through it cancel_url, save_label `liveTitle` on the root x-data mirrors the title field as the host types, so every card frame (steps 2 and 5, and the create mode skeleton) shows the new title before the save. Each step pane carries data-composer-step="N" and the root listens for a window event composer-goto-step {step: N}: that is how anything outside Alpine (the guided tour in static/js/pl_tour.js) reveals a pane before pointing at something inside it. The step tabs ("how much of the form have I filled in?") and the review pipeline card ("where is my class with the reviewers?") are two components with two meanings (§C.4). Do not merge them. {% endcomment %}
