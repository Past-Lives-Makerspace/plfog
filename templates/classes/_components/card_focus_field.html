{% comment %} The catalog card focal point tool (design spec §B.3): the right hand pane of the composer's "Your Photo, Two Shapes" section. Renders the REAL card image strip (classes/public/_class_card_media.html) inside two card shaped frames, one at the width the catalog packs on a laptop and one at the width it packs on a phone, both driven live by two sliders. Only the media block renders, on purpose: the editor has no CatalogGroup, and a class offered on several date sets would get a confidently wrong single date body. Expects `form` (with the hidden card_focus field from _CardFocusMixin) and `offering`, which may be unsaved or have no photo yet. Both card frames sit inside .cp-page, so the .cls-card picks up the catalog's real border, radius, and overflow, and .cls-media supplies the 150px height. The two widths are derived in the CSS comment above .pl-card-focus__frame--laptop. {% endcomment %}
