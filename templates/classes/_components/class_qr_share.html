{% comment %} Share & Print card for a class: a thin wrapper over the shared components/qr_share_card.html. Expects `offering` (saved) and `can_print_marketing` (from the view: published, or an admin looking at a draft). The link + QR both use the slug-proof permalink (offering.qr_url), so they always match and a printed code survives a slug change. The hint is computed HERE and passed to the shared card as one string, since the shared card takes one pre-computed hint. Before publication the flyer button and the QR downloads are absent, not disabled: the card shows offering.MARKETING_LOCKED_REASON in their place (the shared card's locked_note), and the two views refuse their URLs with the same sentence, so a guessed link learns the same thing. The tour key sits on the wrapper, not the button, so the "Print a Flyer or QR" tour stop still has a target while the button is absent. {% endcomment %} {% url 'classes:class_qr' offering.pk 'svg' as class_qr_svg_url %} {% url 'classes:class_qr' offering.pk 'png' as class_qr_png_url %}
