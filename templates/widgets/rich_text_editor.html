{% comment %}Quill rich-text editor over a hidden textarea (core.widgets.RichTextEditorWidget / PageContentEditorWidget). Include "_components/rich_editor_assets.html" once on the page — it loads Quill AND the shared rich-editor-init.js that initializes every mount (keyed on data-rte-for, so multiple editors coexist). No per-instance script here on purpose: formset rows cloned client-side via template.innerHTML never execute embedded scripts (FRONTEND.md rule 16), so all initialization is driven by window.plRteInitAll() — run on DOMContentLoaded, after htmx settles, and by any "+ Add" row-clone handler. PageContentEditorWidget sets data-rte-seed="server" and pre-renders the stored value (legacy Markdown or saved rich HTML) into the mount, so a Markdown body opens as formatted rich text. Saving then writes Quill's HTML back — a one-way, explicit Markdown→HTML conversion. The mount carries no id, on purpose. When a boosted Save redirects back to the same page, htmx settles the class of every element whose id is on both pages, writing the server's bare "pl-rte" over the classes Quill added during the swap. data-rte-for is the mount's key.{% endcomment %}
