{% comment %} Add to calendar on the event page: this one event into the viewer's own calendar, never a subscription to the whole makerspace calendar (that is the Community Calendar's Subscribe menu). Grouped by calendar app, because that is the choice a viewer makes. Google Calendar gets Google's own "create this event" link, a plain https URL that works in every browser and that the native shells hand to the system. Apple Calendar, Outlook and the rest take the single-event .ics, an attachment: hx-boost="false" and data-pl-download (FRONTEND.md rule 24), so inside the native app that row is hidden and Google Calendar remains. Parameters: google_event_url — hub.calendar_entries.google_calendar_event_url() ics_url — hub_event_ics with the page's ?date=, so both rows start on the date shown button_class — the trigger's classes (primary, or ghost beside Join online) {% endcomment %}
