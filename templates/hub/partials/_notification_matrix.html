{% load hub_tags %} {% comment %} The event x channel notification preference grid. Shared by a member's own settings page (_notifications_settings.html), the no-login email-preferences page and the admin member-edit Permissions tab, so an admin can edit a member's notifications for them. The form posts to the current page with form_id=notifications; each host view saves the matrix for the right user. Layout (#524): an "Everything" bar, then the sections from build_matrix. Admin / Permissions comes first when the viewer has rows in it, framed, with a "Whole section" bar and one grid per permission group; each member topic is one grid. Every grid with at least one editable cell gets a second header row of bulk switches: All, then On | Off under each channel its rows let you change. The bell never gets a control. Padlocked, bell and unlinked-Discord cells render disabled, so plNotifBulk's :not(:disabled) never touches them. Every rendered row still posts its live boxes, which is what keeps save_matrix from reading a missing box as off. Context: notif_matrix — build_matrix output: sections, each holding blocks of rows. notif_page_channels — page_editable_channels(notif_matrix): the Everything bar's channels. notif_channels, notif_channel_labels — the grid's columns. matrix_self — True on the member's own page ("you"); False when an admin edits someone else's ("this member"). Defaults falsy → the admin phrasing. capabilities_url — optional; when set, a "Manage your admin duties" link on the Admin / Permissions note (only shown on one's own page). prefs_token — optional no-login token carried through on the email-link flow. {% endcomment %}
