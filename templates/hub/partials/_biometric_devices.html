{% comment %} "Signed In Devices" card on the Account tab of settings. Lists the phones that can sign this member in with a face or a fingerprint, one row each, with a Revoke button per row. The list is server rendered from BiometricCredential.objects.active_for(request.user), so it is honest on the web too: a member can see and kill a phone's access from a laptop. The app-only half ([data-biometric-app-only]) starts hidden. static/js/biometric-auth.js reveals it inside the native app and fills in the "Turn on ..." button, which is where the enrollment offer's Not Now sends people. A browser never sees it, because there is no Keychain to put a secret in. This whole card is the htmx swap target of a Revoke, so its outer element carries the id. Context: biometric_credentials. {% endcomment %}
