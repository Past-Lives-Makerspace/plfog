{% comment %} The Spotlight messages ticker at the very top of Home (#889, a ticker since #935): what admins post in Admin Tools > Spotlight, in their order, on one slim line that crawls right to left like a news feed, a dot between messages. Styles in static/css/home-announcements.css. The track holds the list twice, the second copy aria-hidden and inert, and moves left by one list's width per loop, so the crawl never jumps; a screen reader reads the list once. The script after it sets the loop's length from the list's width and the crawl speed admins set on Admin Tools > Spotlight (#942, SiteConfiguration.spotlight_crawl_speed, read from the feature_flags context processor), so the speed holds however much text there is, and makes each list at least as wide as the line, so one short message still loops cleanly. The track and the pacing are shared with that page's preview (hub/partials/_ticker_track.html, _ticker_pace_script.html). Hover or focus inside holds it still, so a link can be clicked. Under prefers-reduced-motion it does not move: the copy is hidden and the messages wrap, all shown at once. The X closes it in this browser until the set of live messages changes: it keeps the ticker's signature (hub.home.HomeBanner, ids and last saves) in localStorage, and the script removes the ticker before first paint while the stored signature still matches. Every storage read and write is in a try, so with storage blocked the ticker simply shows. banner — a hub.home.HomeBanner {% endcomment %}
