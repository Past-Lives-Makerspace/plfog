{% comment %} "Push On This Device" card, shown above the notification matrix on the settings page. The matrix has a Push column, but nothing there tells a member whether push actually works on the phone in their hand, and there is no way back if they dismissed the OS prompt. This card is that missing piece. It starts hidden and only the native app reveals it: a normal browser has no client-side Web Push flow in this codebase (nothing calls /webpush/subscribe/), so there is no browser push state to honestly describe. All of the plugin work happens in static/js/native-push.js, which exposes window.PLNativePush. This card never touches a Capacitor plugin directly, so the Android/iOS split lives in exactly one place. Context: push_device_count (omitted for token-scoped viewers, who get no card). {% endcomment %}
