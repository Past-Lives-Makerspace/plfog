# docs/plans

A plan here is scaffolding for one open ticket. It exists so the engineer building the
ticket and the reviewer reading the PR see the same steps.

The plan lives here only while its ticket is open. The PR that closes the ticket deletes
the plan in its final commit, because the plan is also posted on the issue and the PR
carries the record of what was actually built. Anything found here for a closed ticket is
a leftover and can be removed on sight.

Name plans `YYYY-MM-DD-<issue>-<slug>.md`.
